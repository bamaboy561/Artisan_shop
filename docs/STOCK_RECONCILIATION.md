# Сверка остатков

В админке откройте «Товары», блок обновления цен и остатков.

1. Выберите «Только остатки» (выбрано по умолчанию).
2. Загрузите исходный XLS/XLSX или CSV и нажмите «Проверить файл».
3. По умолчанию показаны расхождения. Поиск работает по названию и артикулу; фильтр переключает расхождения количества, проблемные совпадения, отсутствующие товары и совпавшие остатки. Список разбит на страницы по 50 строк, поиск охватывает весь результат.
4. Сравните колонки «На сайте», «В файле», «Разница». Разница = количество файла минус количество сайта.
5. Отметьте проверенные строки. «Выбрать доступные в текущем списке» выбирает все допустимые строки текущего фильтра и поиска, включая другие страницы. При смене фильтра выбор сохраняется.
6. Нажмите «Применить» и подтвердите количество выбранных товаров.
7. Скачайте «Отчёт CSV», чтобы получить полный результат сверки, включая товары вне файла.

## Защита данных

- Режим «Только остатки» не меняет цены. Распознанный бухгалтерский отчёт остатков не меняет цены и в режиме «Цены и остатки».
- При наличии артикула сопоставление идёт только по артикулу. Без артикула допустимо точное уникальное название (без учёта регистра, повторных пробелов и ё/е); такие строки обозначены отдельно и требуют выбора пользователем.
- Неоднозначные совпадения, повторы товаров и ошибочные числа нельзя выбрать для записи.
- «Нет в файле» не означает нулевой остаток: отчёт может содержать не все склады и группы. Такие товары не изменяются.
- «Нет на сайте» не создаёт товар. Для создания карточек используйте полный импорт.
- Дробные остатки видны в исходном значении и с единицей измерения бухгалтерского отчёта, но пока не записываются: база каталога хранит целое количество. Они не округляются автоматически.
- Перед записью сервер заново читает файл и каталог, проверяет отпечаток предпросмотра и выбранные строки. Конкурентные изменения защищены проверкой версии товара.
- После обновления колонка «На сайте (было)» показывает значение до этой операции. Статус строки показывает результат записи.

Полный CSV является отчётом, не механизмом автоматического отката. Постоянная история сверок, откат остатков и дробный учёт требуют отдельной доработки.
