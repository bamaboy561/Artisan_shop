# Прайс работ по распилу

Администратор или супер-администратор: **Распил → Прайс работ**.
Заполните стоимость распила за лист и стоимость кромления за погонный метр.
Тарифы задаются в сомах, до двух знаков после запятой. Ноль допустим.

Сумма работ = количество листов × тариф распила + метраж кромления × тариф кромления.
Материалы не включаются. Итог округляется до целого сома после сложения.
Укажите метраж 0, если работа по кромлению не требуется.

Новые заявки сохраняют текущие тарифы. При изменении количества сумма пересчитывается
по сохранённым тарифам, а не по новому прайсу. Если количество листов неизвестно
или указана кромка без метража, сумма остаётся «Не рассчитана».

Старые заявки не меняются автоматически. В карточке есть кнопка **Рассчитать по прайсу**;
для изменения сохранённых тарифов — **Пересчитать по текущему прайсу**.
Такой пересчёт сохраняется в истории заявки с сотрудником, старой и новой суммой.

Сумма отображается в карточке, маршрутном листе, таблице отчёта и выгрузке CSV/текста.
При переводе заявки на распил в обычный заказ переносится сохранённая сумма работ.
Итог отчёта за выбранные даты исключает отменённые заявки. Отменённые строки остаются
в подробном списке со своим статусом. Количество рассчитанных заявок указано отдельно.
Это стоимость заказанных работ, не подтверждённая выручка или оплата.

Данные хранятся в существующих Request.quotedTotal и SiteSetting. Миграция не нужна.
Пока прайс не заполнен, сохраняется прежнее ручное указание суммы.
