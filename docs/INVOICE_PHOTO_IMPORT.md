# Накладная по фото

В разделе «Продажи в зале» доступны Excel и Фото. Распознавание фото включается
только при наличии серверной переменной `OPENAI_API_KEY`.

## Подключение

1. Создать отдельный проект OpenAI API, подключить оплату и задать лимиты расходов.
2. Добавить ключ в Vercel → artisan-shop-vercel → Settings → Environment Variables,
   имя `OPENAI_API_KEY`, окружение Production. Не использовать NEXT_PUBLIC и не
   отправлять ключ сотрудникам или в чат.
3. Модель по умолчанию `gpt-4.1-mini`; можно задать `INVOICE_OCR_MODEL` для модели,
   поддерживающей Responses API, изображения и Structured Outputs.
4. Выполнить новый деплой и проверить одну накладную с известными значениями.

## Работа сотрудника

1. Выбрать Фото и файл или Камеру на телефоне. Одна целая страница за попытку.
2. Подтвердить отправку фото внешнему сервису и нажать «Распознать».
3. Сверить каждую строку с оригиналом, выбрать ненайденные товары, исправить
   количество и цены. Для сложных многостраничных документов использовать Excel.
4. Подтвердить проверку и перенести позиции в продажу. Затем выбрать клиента и
   сохранить продажу отдельно. Распознавание само заказ не создаёт.

## Защита и ограничения

- Доступ только сотрудникам с правом продаж; ключ никогда не отдаётся браузеру.
- Браузер уменьшает фото до 2400 пикселей и JPEG до 3 МБ (до загрузки на Vercel).
- Сервер проверяет реальные данные изображения, убирает EXIF/GPS, принимает
  только JPG/PNG/WebP. PDF, HEIC и многостраничные изображения не поддерживаются.
- Фото не сохраняется в базе или файловом хранилище сайта; локальный оригинал
  доступен в предпросмотре до закрытия страницы. Сервис OpenAI получает сжатое
  фото; `store:false` не является обещанием отсутствия хранения у провайдера.
  Перед использованием проверить применимые условия обработки данных OpenAI.
- Все распознанные накладные требуют подтверждения, даже при совпадении итогов.
- Неразборчивые числовые поля остаются пустыми; дроби не округляются. Существующие
  проверки целых количеств, цен, остатков и дублей сохраняются.
- Незавершённый ответ, обрезанная таблица и более 100 строк не импортируются.
- Таймаут 75 секунд, без автоматических платных повторов. Ограничение сотрудника:
  одна попытка в 30 секунд и 50 в сутки UTC. Счётчик хранится атомарно в SiteSetting,
  без миграции схемы. Неудачные обращения также считаются попытками.
- Цены берутся из фото, не перезаписывают каталог и не получают повторную скидку.
- Реальное качество распознавания нужно проверить после подключения API на
  нескольких накладных; мок-тесты не заменяют эту проверку.

Документация API: https://developers.openai.com/api/docs/guides/images-vision
и https://developers.openai.com/api/docs/guides/structured-outputs.
