# Каталог с фотографиями

В админке: **Товары → Каталог с фото**.

1. Выберите бренд или «Все бренды».
2. Выберите PDF или Excel (.xlsx).
3. При необходимости включите «Только с положительным остатком».
4. Нажмите «Скачать» и дождитесь формирования.

Выгружаются активные товары: главное фото, полный артикул, название,
бренд, путь категории, размеры, толщина, цена с действующей акцией и остаток.
Персональные скидки и бонусы клиента в цены каталога не включаются.
Дата снимка указана по времени Бишкека. Остатки и цены в скачанном файле
не обновляются автоматически: для актуальных данных скачайте его заново.

Фотографии встроены в файлы. Недоступные изображения отмечаются в файле,
товары не исключаются. После скачивания показывается число недоступных фото.
Пустые цена и остаток не подменяются нулём.

Для большого каталога удобнее выгружать отдельные бренды. При превышении
времени подготовки или размера файл не выдаётся частично.
Существующая кнопка «Скачать каталог Excel» сохраняет полную техническую
выгрузку с тремя листами, включая неактивные товары, без встроенных фото.

Доступ ограничен ролями общего раздела админки, проверяется на сервере.
Экспорт ничего не меняет в товарах, остатках, заказах или бонусах.
